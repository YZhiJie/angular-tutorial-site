EP.01 standalone 登场与 signal 心跳 ​

对应正文：01-first-app（1 没有 NgModule 的 Angular 应用 / 2 创建并启动工程 / 3 可运行示例 / 4 代码拆解）· 示例：examples/hello-binding · Playground id：hello-binding

剧情回顾 ​

  • 第 1 格：标签君发现 Angular 工程里没有了 AppModule，bootstrapApplication(App, appConfig) 直接就能起——Angular 22 默认 standalone，imports 数组代替了旧的 declarations。
  • 第 2 格：码叔把 signal 的四种姿势摆出来：signal(0) 建容器 → count() 读值 → count.set(5) 替换 → count.update(v => v+1) 计算。模板里必须加括号。
  • 第 3 格：像素酱在模板里同时秀四种绑定：插值、事件、class、管道——每一处绑定都会记住"我依赖哪个 signal"。
  • 第 4 格：码叔结案——Angular 22 默认 zoneless，Zone.js 不再替你追异步，signal 写入才是真信号。

知识点拆解 ​

第 1 格 · standalone 登场 ​

Angular 22 新工程默认 standalone 形态：

  • src/main.ts 直接 bootstrapApplication(App, appConfig)，不需要根 NgModule；
  • 组件装饰器里不再写 @NgModule，但要写 imports: [...] 声明模板用到的指令、管道；
  • provideXxx() 系列函数往 appConfig.providers 追加应用级能力（路由、HTTP、错误监听）。
ts
// src/main.ts
import { bootstrapApplication } from '@angular/platform-browser';
import { App } from './app/app';
import { appConfig } from './app/app.config';
bootstrapApplication(App, appConfig);

第 2 格 · signal 到底是什么 ​

signal 是个函数容器：调用它拿值，.set() 替换值，.update() 基于旧值推导新值。

ts
const count = signal(0);
count();              // 0，读 + 建立依赖
count.set(5);         // 直接替换，调度器通知模板刷新
count.update(v => v + 1);  // 基于旧值的计算

两个必须记住的规则：

  1. 模板里写 count() 不是 count——后者会把函数本身显示出来；
  2. .update() 避免丢失——连续点击时，每一次都在最新值上累加。

第 3 格 · 四类绑定手速秀 ​

模板里的绑定表达式求值都会走 Angular 编译器，结果写进组件上下文：

类型写法例子
插值{ { expr } }{ { framework() } }
事件(event)="handler"(click)="increase(1)"
属性/class[prop]="expr"[class.hot]="count() >= 10"
管道expr | pipe: arg{ { today() | date: 'yyyy-MM-dd' } }

第 4 格 · zoneless 那些坑 ​

Angular 22 默认关闭 Zone.js——只有 signal 写入、模板事件、Effect 显式调度这三种触发刷新的途径。任何你在代码里直接改的普通字段、fetch 回调里赋值的普通变量，模板都不会自动知道。

坑点清单 ​

🔗 正文对照：常见坑表格

  1. 模板写 count 显示函数体不是数字 → signal 必须加括号调用；
  2. 给 signal 直接赋值 count = 5 报只读属性 → 用 .set() 或 .update() 写入；
  3. 模板里用 Number($any($event.target).value) 被编译器当作组件属性 → 用组件方法包一层；
  4. 用旧 *ngIf / *ngFor 混在 @if / @for 里 → 新控制流是编译器语法，独立于指令。

自测 3 题（含答案） ​

  1. 模板里为什么 { { count } } 会显示函数源码？——count 是 signal 返回的函数容器，必须调用 { { count() } } 才能拿到值。
  2. .set() 和 .update() 应该怎么选？——全新值覆盖用 .set()；基于旧值计算用 .update()，避免丢失。
  3. Angular 22 默认为什么"模板不刷新"？——默认 zoneless，只有 signal 写入、模板事件、Effect 显式调度才触发变更检测；普通字段赋值不会。
