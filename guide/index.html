六阶段学习路线 ​

这套教程假设你会 JavaScript / TypeScript，但不要求事先接触过 Angular。每一章都遵循同一结构：学习目标 → 概念讲解 → 可运行示例 → 常见坑 → 练习 → 自测。

示例不是截图或伪代码，而是 examples/ 下的真实 Angular 22 工程。页面中的 Playground 会在浏览器里启动完整开发服务器，你可以直接改代码并看到结果。

建议的学习方式 ​

  1. 先跑再读：打开章节里的 Playground，点击「立即加载」在页面内编辑运行，或在新窗口打开沙箱。
  2. 每章至少改一次代码：把示例中的参数、条件或数据结构改掉，观察视图如何变化。
  3. 先做练习再看自测：自测题用于检查理解，不替代动手。
  4. 按阶段提交：每完成一篇，把练习代码整理成自己的小项目，而不是只收藏文档。

版本基线 ​

  • Angular 22.2.3，standalone 组件为默认形态
  • TypeScript 6.0.x
  • Node.js 22.13+（CI 使用 Node 24）
  • 包管理器 pnpm 12
  • 文档框架 VitePress 1.6.4

关于 zoneless

Angular 22 默认使用 zoneless 变更检测。教程会明确区分「signal 驱动」「事件驱动」与「手动变更检测」三种刷新路径，避免把旧版 Zone.js 的经验直接套用。

代码与站点如何同步 ​

examples/<id>/ 是示例的唯一真源。构建前运行 pnpm sync:examples，把源码汇总为 docs/.vitepress/generated/examples.json；pnpm sync:sandboxes 再把示例发布为 CodeSandbox 在线沙箱，Playground 组件按 id 加载对应的沙箱。

因此：改示例只改 examples/，不要直接改生成物。CI 会校验生成物与源码一致，并检查每个 <Playground> 引用的示例是否存在。
